## Capability

A reusable engineering function that solves a complete engineering problem through knowledge, assessment, automation and operational guidance.

---

## Provider

A technology-specific implementation of a capability.

Examples:

- PostgreSQL Provider
- SQL Server Provider
- MySQL Provider

---

## Rule

A condition used to evaluate collected information and produce engineering recommendations.

---

## Assessment

The process of collecting information, evaluating rules and producing engineering findings.

---

## Knowledge

Documented engineering expertise independent from any implementation.

---
